# ---- quality metrics ----
# DNSMOS P.835. This CPU build is the safe default and works everywhere.
#
# On a GPU server, DO NOT just `pip install onnxruntime-gpu`: it must match
# torch's CUDA MAJOR version, or its provider library fails to load
# ("libcublasLt.so.13: cannot open shared object file") and onnxruntime falls
# back to CPU *silently*. Verified from the wheels' own requires_dist:
#
#     onnxruntime-gpu <= 1.26.0  ->  CUDA 12
#     onnxruntime-gpu >= 1.27.0  ->  CUDA 13
#
# Check torch, then install the matching line - removing BOTH packages first,
# because they share one directory and uninstalling either guts the other:
#
#     python -c "import torch; print(torch.version.cuda)"
#     pip uninstall -y onnxruntime onnxruntime-gpu
#     pip install --no-cache-dir "onnxruntime-gpu<1.27"    # CUDA 12
#     pip install --no-cache-dir "onnxruntime-gpu>=1.27"   # CUDA 13
#
# scripts/setup_server.sh does this automatically. `vcprep doctor` verifies it.
